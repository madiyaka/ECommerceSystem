1. Objective

The goal of this project is to design and implement a simple console-based e-commerce system in Java. The system manages users (customers and employees), products (books, electronics and clothing) and orders. Customers can browse products, fill a shopping cart and place orders; employees can add products and users, restock products and view all orders.

The project is used to practise the main principles of object-oriented programming: class design with attributes and methods, encapsulation, inheritance, abstraction and polymorphism, together with the Java Collections Framework (ArrayList) and console input with Scanner.

5. Design and Implementation Notes

5.1 Encapsulation

Every attribute in every class is private. Other classes access data only through public getters and setters. Setters are used to protect the object's state, for example Product.setPrice() and setStockQuantity() reject negative values, and Employee.setSalary() rejects a negative salary. The password has a setter but no getter: it can only be checked with checkPassword(), so it is never exposed. Methods that return lists (Store.getProducts(), Order.getItems(), ...) return a copy of the internal ArrayList, so code outside the class cannot add or remove elements behind the class's back. Stock can only change through reduceStock() / increaseStock(), which check the values.

5.2 Inheritance and abstraction

User and Product are declared abstract because a "plain" user or product never exists — there is always a concrete type. The common attributes (id, name, price, stock...) and common behaviour (displayInfo(), isInStock(), checkPassword()) are written once in the superclass and reused by all subclasses. Subclass constructors call super(...) to initialise the inherited private fields. The role of a user ("CUSTOMER" / "EMPLOYEE") is set automatically by the subclass constructor, so it can never be inconsistent with the real type.

5.3 Polymorphism

Product.displayInfo() prints the common fields and then calls the abstract methods getCategory() and getDetails(). Each subclass overrides them (@Override), so when the store loops over an ArrayList<Product> and calls displayInfo(), a book shows its author, electronics show brand and warranty, and clothing shows size and color. The same idea is used in User.displayInfo() with getExtraInfo(). After login, instanceof is used to decide whether the customer menu or the employee menu is shown.

5.4 Collections

Store keeps three collections: ArrayList<User>, ArrayList<Product> and ArrayList<Order>. Because the lists use the superclass types, one list can hold customers and employees (or books, electronics and clothing) together. Order keeps an ArrayList<OrderItem>, and the customer's shopping cart is a List<OrderItem> that lives only during the customer's session.

5.5 Design decisions

  • OrderItem class. The requirements say an order contains a "list of products". A plain ArrayList<Product> cannot store how many units were bought, and if the product's price changed later, old receipts would change too. OrderItem stores the product, the quantity and the unit price at the time of purchase.
  • Store class (service layer). All data and business rules are in Store; the menu code in ConsoleApp only reads input and prints output. This separation makes the code easier to read and would let us replace the console with a GUI without changing the model.
  • Safe order placement. Store.placeOrder() first checks the stock of every cart item and only then reduces stock and creates the order, so an order is either completed fully or not at all.
  • Total amount consistency. Order.totalAmount has no setter; it is recalculated by calculateTotal() every time an item is added, so it always matches the items.
  • Unique e-mail. Store.addUser() refuses a second user with the same e-mail, because e-mail is used to log in.
  • InputHelper. All Scanner input goes through this class, which repeats the question until the value is valid, so typing letters instead of a number does not throw an exception.
  • ID generation. The store generates IDs with counters (nextUserId, ...), so IDs are unique and the user does not need to type them.

7. Conclusion

A working console e-commerce system was designed and implemented in Java. The requirement analysis produced ten classes in five packages. Two inheritance hierarchies (User → Customer/Employee and Product → Book/Electronics/Clothing) remove duplicated code and, together with abstract methods, give polymorphic behaviour when products and users are listed. Encapsulation with private fields and validating setters keeps every object in a valid state, and ArrayList collections store all data. Separating the model, the service (Store) and the user interface (ConsoleApp) keeps the code clear and easy to extend — for example, adding a new product category only requires one new subclass of Product.

Possible improvements: saving data to files or a database, hashing passwords, searching/filtering products, and order statuses (paid, shipped, delivered).

package ecommerce.model.user;

/**
 * Base class for every person who can log in to the system.
 * It is abstract because a "plain" user never exists: every user is
 * either a Customer or an Employee.
 */
public abstract class User {

    private int userId;
    private String name;
    private String email;
    private String password;
    private String role;

    protected User(int userId, String name, String email, String password, String role) {
        this.userId = userId;
        this.name = name;
        this.email = email;
        this.password = password;
        this.role = role;
    }

    /** Compares the given password with the stored one (password is never exposed by a getter). */
    public boolean checkPassword(String candidate) {
        return password.equals(candidate);
    }

    /** Prints a one-line summary of the user. Subclasses add their own details. */
    public void displayInfo() {
        System.out.printf("#%-3d %-10s %-20s %-25s%s%n",
                userId, role, name, email, getExtraInfo());
    }

    /** Hook for subclasses to append role-specific information to displayInfo(). */
    protected abstract String getExtraInfo();

    public int getUserId() {
        return userId;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public String getEmail() {
        return email;
    }

    public void setEmail(String email) {
        this.email = email;
    }

    public void setPassword(String password) {
        this.password = password;
    }

    public String getRole() {
        return role;
    }
}

A.5 src/ecommerce/model/product/Product.java

package ecommerce.model.product;

/**
 * Base class for everything the store sells.
 * Abstract because every real product belongs to a category (Book, Electronics, Clothing).
 */
public abstract class Product {

    private int id;
    private String name;
    private double price;
    private int stockQuantity;

    protected Product(int id, String name, double price, int stockQuantity) {
        this.id = id;
        this.name = name;
        setPrice(price);
        setStockQuantity(stockQuantity);
    }

    /** Prints the common product fields followed by the category-specific details. */
    public void displayInfo() {
        System.out.printf("#%-3d %-12s %-28s %10.2f KZT  stock: %-4d %s%n",
                id, getCategory(), name, price, stockQuantity, getDetails());
    }

    /** Category name shown in listings, e.g. "Book". */
    public abstract String getCategory();

    /** Category-specific attributes as text, e.g. "author: ...". */
    protected abstract String getDetails();

    public boolean isInStock(int quantity) {
        return quantity > 0 && quantity <= stockQuantity;
    }

    /** Removes sold items from stock. Called only after isInStock() was checked. */
    public void reduceStock(int quantity) {
        if (!isInStock(quantity)) {
            throw new IllegalArgumentException("Not enough stock for " + name);
        }
        stockQuantity -= quantity;
    }

    public void increaseStock(int quantity) {
        if (quantity <= 0) {
            throw new IllegalArgumentException("Quantity must be positive");
        }
        stockQuantity += quantity;
    }

    public int getId() {
        return id;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public double getPrice() {
        return price;
    }

    public void setPrice(double price) {
        if (price < 0) {
            throw new IllegalArgumentException("Price cannot be negative");
        }
        this.price = price;
    }

    public int getStockQuantity() {
        return stockQuantity;
    }

    public void setStockQuantity(int stockQuantity) {
        if (stockQuantity < 0) {
            throw new IllegalArgumentException("Stock cannot be negative");
        }
        this.stockQuantity = stockQuantity;
    }
}

A.9 src/ecommerce/model/order/Order.java

package ecommerce.model.order;

import ecommerce.model.user.Customer;

import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;
import java.util.ArrayList;
import java.util.List;

/**
 * An order placed by one customer, containing one or more order items.
 */
public class Order {

    private static final DateTimeFormatter DATE_FORMAT = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm");

    private int orderId;
    private Customer customer;
    private ArrayList<OrderItem> items;
    private double totalAmount;
    private LocalDateTime orderDate;

    public Order(int orderId, Customer customer) {
        this.orderId = orderId;
        this.customer = customer;
        this.items = new ArrayList<>();
        this.totalAmount = 0;
        this.orderDate = LocalDateTime.now();
    }

    public void addItem(OrderItem item) {
        items.add(item);
        calculateTotal();
    }

    /** Recalculates totalAmount from the items, so the total is always consistent. */
    public double calculateTotal() {
        double sum = 0;
        for (OrderItem item : items) {
            sum += item.getSubtotal();
        }
        totalAmount = sum;
        return totalAmount;
    }

    public void printReceipt() {
        System.out.println("==================================================");
        System.out.println(" RECEIPT  -  Order #" + orderId);
        System.out.println(" Date:     " + orderDate.format(DATE_FORMAT));
        System.out.println(" Customer: " + customer.getName() + " (" + customer.getEmail() + ")");
        System.out.println(" Ship to:  " + customer.getShippingAddress());
        System.out.println("--------------------------------------------------");
        for (OrderItem item : items) {
            System.out.printf(" %-24s %3d x %9.2f = %10.2f%n",
                    item.getProduct().getName(), item.getQuantity(),
                    item.getUnitPrice(), item.getSubtotal());
        }
        System.out.println("--------------------------------------------------");
        System.out.printf(" TOTAL: %38.2f KZT%n", totalAmount);
        System.out.println("==================================================");
    }

    public int getOrderId() {
        return orderId;
    }

    public Customer getCustomer() {
        return customer;
    }

    /** Returns a copy so callers cannot modify the order's items directly. */
    public List<OrderItem> getItems() {
        return new ArrayList<>(items);
    }

    public double getTotalAmount() {
        return totalAmount;
    }

    public LocalDateTime getOrderDate() {
        return orderDate;
    }
}

package ecommerce.service;

import ecommerce.model.order.Order;
import ecommerce.model.order.OrderItem;
import ecommerce.model.product.Product;
import ecommerce.model.user.Customer;
import ecommerce.model.user.User;

import java.util.ArrayList;
import java.util.List;

/**
 * Holds all data of the shop in ArrayLists and contains the business rules
 * (login, adding users/products, placing orders). The console UI only talks to this class.
 */
public class Store {

    private ArrayList<User> users = new ArrayList<>();
    private ArrayList<Product> products = new ArrayList<>();
    private ArrayList<Order> orders = new ArrayList<>();

    private int nextUserId = 1;
    private int nextProductId = 1;
    private int nextOrderId = 1;

    // ---------- ID generation ----------

    public int generateUserId() {
        return nextUserId++;
    }

    public int generateProductId() {
        return nextProductId++;
    }

    // ---------- Users ----------

    public void addUser(User user) {
        if (findUserByEmail(user.getEmail()) != null) {
            throw new IllegalArgumentException("A user with email " + user.getEmail() + " already exists");
        }
        users.add(user);
    }

    public User findUserByEmail(String email) {
        for (User user : users) {
            if (user.getEmail().equalsIgnoreCase(email)) {
                return user;
            }
        }
        return null;
    }

    /** Returns the matching user, or null if the email/password is wrong. */
    public User login(String email, String password) {
        User user = findUserByEmail(email);
        if (user != null && user.checkPassword(password)) {
            return user;
        }
        return null;
    }

    public List<User> getUsers() {
        return new ArrayList<>(users);
    }

    // ---------- Products ----------

    public void addProduct(Product product) {
        products.add(product);
    }

    public Product findProductById(int id) {
        for (Product product : products) {
            if (product.getId() == id) {
                return product;
            }
        }
        return null;
    }

    public List<Product> getProducts() {
        return new ArrayList<>(products);
    }

    // ---------- Orders ----------

    /**
     * Creates an order from the customer's cart.
     * Stock is checked for every item first, so either the whole order succeeds or nothing changes.
     */
    public Order placeOrder(Customer customer, List<OrderItem> cart) {
        if (cart.isEmpty()) {
            throw new IllegalArgumentException("Cart is empty");
        }
        for (OrderItem item : cart) {
            if (!item.getProduct().isInStock(item.getQuantity())) {
                throw new IllegalArgumentException("Not enough stock for " + item.getProduct().getName()
                        + " (available: " + item.getProduct().getStockQuantity() + ")");
            }
        }

        Order order = new Order(nextOrderId++, customer);
        for (OrderItem item : cart) {
            item.getProduct().reduceStock(item.getQuantity());
            order.addItem(item);
        }
        orders.add(order);
        return order;
    }

package ecommerce.ui;

import java.util.Scanner;

/**
 * Small wrapper around Scanner that keeps asking until the input is valid,
 * so a typo never crashes the program.
 */
public class InputHelper {

    private Scanner scanner;

    public InputHelper(Scanner scanner) {
        this.scanner = scanner;
    }

    public String readLine(String prompt) {
        System.out.print(prompt);
        return scanner.nextLine().trim();
    }

    public String readNonEmpty(String prompt) {
        while (true) {
            String value = readLine(prompt);
            if (!value.isEmpty()) {
                return value;
            }
            System.out.println("  Value cannot be empty.");
        }
    }

    public int readInt(String prompt) {
        while (true) {
            String value = readLine(prompt);
            try {
                return Integer.parseInt(value);
            } catch (NumberFormatException e) {
                System.out.println("  Please enter a whole number.");
            }
        }
    }

    public int readPositiveInt(String prompt) {
        while (true) {
            int value = readInt(prompt);
            if (value > 0) {
                return value;
            }
            System.out.println("  Number must be greater than 0.");
        }
    }

    public double readNonNegativeDouble(String prompt) {
        while (true) {
            String value = readLine(prompt);
            try {
                double number = Double.parseDouble(value);
                if (number >= 0) {
                    return number;
                }
                System.out.println("  Number cannot be negative.");
            } catch (NumberFormatException e) {
                System.out.println("  Please enter a number (e.g. 1500 or 99.90).");
            }
        }
    }
}

    private void addToCart(List<OrderItem> cart) {
        listProducts();

        if (product == null) {
            System.out.println("No product with ID " + id + ".");
            return;
        }
        int quantity = input.readPositiveInt("Quantity: ");

        // If the product is already in the cart, increase its quantity instead of adding a second line.
        OrderItem existing = null;
        for (OrderItem item : cart) {
            if (item.getProduct() == product) {
                existing = item;
            }
        }
        int newQuantity = (existing == null) ? quantity : existing.getQuantity() + quantity;
        if (!product.isInStock(newQuantity)) {
            System.out.println("Only " + product.getStockQuantity() + " in stock.");
            return;

        if (existing == null) {
            cart.add(new OrderItem(product, quantity));
        } else {

        }
